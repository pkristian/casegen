== vars.tmpl (constants, longest match, two bindings in one token)
A var binds a placeholder to a constant, so it substitutes outside a loop too:
  shop   Shop   SHOP   shop   Shop

Longest match wins: the two-word name above does not eat the three-word one below,
even though it starts it.
  wholesale_depot   WHOLESALE_DEPOT   wholesaleDepot   wholesale.depot

    '<?= shop_customer_order ?>' => ShopCustomerOrder::class,
    '<?= shop_line_item ?>' => ShopLineItem::class,
